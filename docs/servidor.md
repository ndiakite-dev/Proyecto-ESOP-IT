# Servidor

## Descripción
La infraestructura está basada en un servidor central que proporciona servicios de autenticación, despliegue y almacenamiento a todos los equipos del centro.

## Servicios implementados

### Active Directory
Gestión centralizada de usuarios y equipos.

### DNS
Resolución de nombres dentro del dominio.

### MDT
Captura y despliegue automatizado de equipos.

### WDS
Arranque PXE para instalaciones por red.

### SMB
Compartición de carpetas y recursos.

## Objetivos
- Centralización de servicios.
- Facilitar la administración.
- Simplificar el despliegue de equipos.
- Garantizar una gestión unificada de usuarios y recursos.
